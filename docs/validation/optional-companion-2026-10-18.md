Issue #235. [Design](../design/optional-companion.md). Brim presents recorded
workflow states; these checks establish no expert quality, currentness or S0.

Three pre-fix cases reproduce shared shimmer policy ignoring screen-reader
variables. One effects owner now supplies the accessibility veto to banner and
companion. Ten block/ASCII snapshots cover five still poses; working scan/blink
frames preserve a single foreground per paired pixel. Distinct half-block eyes
remain readable without color. Roles come from the existing palette owner.

Tests cover TTY/width/accessibility vetoes, root/environment/config opt-outs,
nested-command inheritance and reset, static reduced motion, buffered refresh,
cleanup on error/interrupt/cancellation, literal body text, JSON parity and one
unchanged consultation transaction. Actual Pushback rows, not answer wording or
agreements, select the skeptical pose; partial/empty results cannot show success.
Study success requires a clean result whose nonempty findings are all anchored
by existing structural counts. Formation completion alone does not establish it.

A config test initially reused a previously bound startup target. Only its added
companion preference was removed; all other configuration bytes and mode were
preserved, with no credential values retained. Tests now bind a private startup
path and assert that target before writing. Production startup binding and
credential quarantine remain unchanged. The real prompt capture also exposed
cropped numeric keys and parsed `[q]`; three failed layout cases now pass with
literal Text and a padding-aware key width. Visual review then found inherited
muted styling dimming status values and quick-command accents. Explicit label
spans now preserve the existing value/command roles; the ANSI regression fails
before that repair and passes afterward.

formation run passed 1,783 before the final ASCII/menu checks. The full frozen
revision passes 13,453 offline unit tests, with 22 existing platform/optional
skips and 85.53% combined coverage. The independent coverage gate passes.
All 293 strict island files and the two presentation modules pass strict
checking. The wider baseline stays exactly 196 errors in 60 files. Source/gate
