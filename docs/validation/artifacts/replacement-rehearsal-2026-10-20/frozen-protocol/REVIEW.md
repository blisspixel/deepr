# Replacement S0 protocol draft

New synthetic development material, prepared 2026-10-17 Pacific. This is not the missing September S0 baseline. No answers were collected, no reviewer attested the protocol, and no semantic or value gate has passed. The earlier eight-cell diagnostic and its failed constructions remain separate.

## Decision and scope

Test whether a fictional checkpoint advisor can explain a bounded reuse decision, revise advice when a report is withdrawn, preserve still-valid conditions, challenge misleading premises and distinguish unrelated later evidence. This small fixture cannot establish real-world expertise, acquisition quality or retrieval scalability. Every case is development material, not a held-out acceptance case.

The existing four-arm harness supplies current sources to every answer: fresh per-case study, raw static history, a frozen world-1 compiled expert, and an expert maintained before later worlds. Preparation never receives case questions or organizer review criteria. Report preparation resources separately from final-answer resources.

## Proposed execution contract

- Three cumulative worlds contain 4, 8 and 12 source versions. Twelve questions across four arms produce 48 terminal cells, including failures.
- Pin qwen3.8:27b and its recorded digest in policy.json; re-attest installed identity and persistent cloud disablement before execution.
- Context: 32,768 tokens; output ceiling: 4,096 per call; temperature 0; seed 20261018; think false; synopsis/change lenses. Fixed seed does not prove byte identity.
- Each answer requests at most 180 words. All arms share that request and output ceiling. The larger ceiling is proposed after the separate truncated diagnostic, not a claim it guarantees a completed brief.
- Six calls maximum per phase, 600-second call timeout, 1,800-second worker timeout, 20,000-character corpus/chunk ceiling and 8,000-character memory prefix. No paid fallback, tools, canonical learning or automatic default promotion.
- Use a new run root, retain every failed or blocked cell, bind code/model/source/request/answer identities, reconcile every local attempt at $0, and measure canonical expert state before and after. Null integrity results are not passes.
- Worker process separation retains loopback access and does not establish hostile-process OS confinement.
- Before collection, finish an accepted blueprint/placement and reviewer rubric binding using the existing harness. Keep the run directory and arm key away from reviewers; freeze labels before revealing the key. This draft does not fabricate that binding or attestation.

## Proposed review dimensions

An accountable reviewer must define and approve the scoring anchors before collection. Suggested dimensions are applicability, revision and continuity, premise correction, attribution, uncertainty and instruction adherence. Review full answers and delivered evidence, not keyword matches. Preserve negative and missing results. An operationally complete rehearsal still does not establish S4 improvement.
