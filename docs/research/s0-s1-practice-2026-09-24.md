# S0 review and S1 preparation: current practice

Research note, 2026-09-24. Sources were checked on this date through public
web pages and free, keyless endpoints; no paid API was called. Facts below
cite their source. Recommendations are inferences for Deepr and do not change
the [active roadmap](../../ROADMAP.md#active-release-plan) or the
[delivery plan](../plans/living-expertise.md) by themselves.

## S0: what to add before blinded review

**Stale-memory probes.** STALE (May 2026) separates three failure modes when
new evidence silently invalidates memory: noticing the change, resisting a
stale premise, and applying the new state later; the best model scored
55.2%. Small Qwen3 models reused a stale fact 92-100% of the time in the
Memory Trust Gap study (September 2026), and which mitigation helped depended
on model size. Inference: label each existing case by which of these it
probes, and score stale reuse separately from correctness, as the workbook
already does.
[STALE](https://arxiv.org/abs/2605.06527),
[Memory Trust Gap](https://arxiv.org/abs/2609.01852).

**The closest preregistered design.** A July 2026 ablation of LLM-maintained
wiki knowledge bases kept page bodies byte-identical across arms, hashed gold
answers in advance, used a judge from a different model family with
randomized order, and tested non-inferiority. Its preregistered human-judge
agreement gate (kappa 0.60) failed at 0.23 and was reported as a deviation
rather than regraded. Inference: decide in advance what happens when reviewer
agreement is low, and keep that outcome visible.
[Preregistered wiki ablation](https://arxiv.org/abs/2607.04576).

**Judge bias and correction.** Position effects appear even in pointwise
rubric scoring, including option and criterion order. A 21-judge study found
high test-retest reliability alongside position bias, and chance-corrected
agreement 33-41 points below raw agreement. Bias-corrected estimators keep
nominal coverage where naive judge averages can fail.
[Rubric position bias](https://arxiv.org/abs/2602.02219),
[Reliability without validity](https://arxiv.org/abs/2606.19544),
[Correcting judge estimates](https://arxiv.org/abs/2601.05420).
Inference: any model judge must differ from the answering model, run under at
least two presentation orders, and be calibrated against human labels on a
separate set. The 48 cells are few enough for complete human labeling.

**Small-pilot statistics.** Treat the case as the unit, world as a stratum,
and report paired differences with the minimum detectable effect. Twelve
cases detect only large effects; the result is estimation for a go or no-go
decision, not proof.
[Resolution diagnostics](https://arxiv.org/abs/2605.30315),
[Multi-system comparison](https://arxiv.org/abs/2608.22659).

**Freezing.** A hash proves bytes did not change, not when they existed. An
externally timestamped record, such as a pushed tag, is needed for a
preregistration claim.
[Hash freezing is not preregistration](https://arxiv.org/html/2608.20304).

**Placebo control.** A derangement control gives each case another case's
memory, preserving format while breaking relevance. Inference: run it as a
separate diagnostic on a subset before attributing a maintained-arm effect to
memory content; do not add it silently to the four-arm analysis.
[Derangement control](https://arxiv.org/abs/2607.23191).

## S1: prepare before advising

**When to retrieve.** 2026 work decides retrieval from model uncertainty
while assuming both memory and retrieval can be wrong. Local text-only models
do not expose reliable internal signals. Inference: the model lists the
assumptions a question depends on and judges which need current evidence;
code enforces source, byte, time and call limits.
[MACR](https://arxiv.org/abs/2606.20245).

**Freshness is per assumption.** RecencyQA labels how often answers change and
finds context-dependent recency hardest. FreshCache reuses cached material
only within a per-layer staleness budget; only about a third of detected page
changes affected answer correctness, so a changed hash should trigger a
re-check rather than invalidate an answer.
[RecencyQA](https://arxiv.org/abs/2603.16544),
[FreshCache](https://arxiv.org/abs/2607.04281).

**Conflicts stay visible.** Prompting alone does not reliably make a model
prefer current evidence over its prior. Inference: record the dated conflict
in the preparation packet and answer, and leave canonical memory unchanged,
as S1 already requires.
[SHIFT](https://arxiv.org/pdf/2606.27786).

**Free structured currency sources for the Python exemplar**, checked
2026-09-24:

| Need | Source | Access notes |
| --- | --- | --- |
| Versions and yanks | PyPI JSON API and PEP 691 Simple JSON | No key; ETag and `x-pypi-last-serial` support revalidation ([docs](https://docs.pypi.org/api/json/)) |
| Advisories for pinned versions | OSV.dev `v1/query` and `v1/querybatch` | No key or published limit ([API](https://google.github.io/osv.dev/api/)) |
| Interpreter support status | `peps.python.org/api/release-cycle.json` | Static JSON with ETag; lists 3.15 as prerelease with final expected 2026-10-01 ([PEP 790](https://peps.python.org/pep-0790/)) |
| Corroboration only | GitHub advisory REST, endoflife.date | 60 unauthenticated requests per hour on GitHub; endoflife.date lagged 3.15 |

Inference: start S1 acquisition with these structured sources and allowlisted
official changelogs rather than general web search. Store URL, request time,
response `Date` and `Last-Modified`, ETag, SHA-256 of the bytes, applicable
version scope and status for each observation.

**Temporal leakage.** Search-engine date filters leaked post-cutoff pages for
most tested questions. Historical and frozen evaluations should use retained
snapshots, as the source-world design already does.
[Temporal leakage](https://arxiv.org/abs/2602.00758).

## S2 pointers

Graphiti's open August 2026 issue reports that an unscoped model contradiction
check retired about 41% of facts in one graph, mostly false positives. Its
proposed fix restricts candidates structurally before model judgment. That
matches the project boundary: code scopes candidates, calibrated model
judgment decides meaning, and code validates form before any write.
[Graphiti issue 1728](https://github.com/getzep/graphiti/issues/1728).

## Local runtime facts used by the rehearsal

Ollama 0.34.3 was installed. The native chat API accepts `seed`, `think`, and
per-request `num_ctx`, and `/api/tags` reports a model content digest.
Community reports show fixed seed and zero temperature do not guarantee
byte-identical output across loads or platforms, so the rehearsal records
exact requests and responses instead of claiming determinism.
[Chat API](https://docs.ollama.com/api/chat),
[Thinking control](https://docs.ollama.com/capabilities/thinking),
[Determinism report](https://github.com/ollama/ollama/issues/5321).
